# mindattic.com

Personal portfolio for Ryan DeBraal — one hand-authored, self-contained `index.htm` showcasing software, hardware, writing, and visual art. No build step, no framework, no external requests.

[mindattic.com](https://mindattic.com)

---

## What it is

A single `index.htm` with inlined CSS and JavaScript, base64-inlined fonts and images, and a cyberpunk Cyberspace visual style. Open the Network tab: you will see one request.

Sections:

| Section | Content |
|---|---|
| Portfolio | Tabbed project showcase (Software + Hardware tiles) |
| Software | Board-grid of public MindAttic GitHub repos — generated by `fetch-descriptions.ps1` |
| MindAttic Ecosystem | SVG dependency diagram rendered from `diagram/ecosystem.mmd` |
| Hardware | Hand-maintained project cards |
| Writing | Amazon book covers (base64-inlined) with synopses — generated by `fetch-descriptions.ps1` |
| Visual Arts | Art preview grid |

## Stack

`HTML5` · `CSS3` (custom properties, dark Cyberspace palette only) · `Vanilla JavaScript` (IIFE-scoped) · `Canvas 2D` · `SVG`

No React. No Vite. No npm. No CDN.

## Local development

```
# Open it.
start index.htm
```

No dev server. Nothing to compile.

## Content updates

### Refresh Software tiles and Writing synopses

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\Projects\MindAttic\mindattic.com\fetch-descriptions.ps1"
```

GitHub is the source of truth for Software tile descriptions. Amazon is the source of truth for Writing synopses. Edit there, then rerun.

### Add a book

```powershell
powershell -File add-book.ps1 https://www.amazon.com/dp/B0XXXXXXXX
# or: add-book.bat https://www.amazon.com/dp/B0XXXXXXXX
```

### Regenerate the ecosystem diagram

```powershell
powershell -File diagram\render.ps1
```

### Refresh UiUx components (fonts, Cyberspace, PinFooter, WebSnapshot)

Run via deploy — see below.

## Deploy

Use the `/deploy` Claude command, or run directly:

```powershell
cd D:\Projects\MindAttic\MindAttic.Deploy
npm run deploy -- --site mindattic.com
```

The pipeline: pulls `MindAttic.UiUx`, syncs subscribed components into `index.htm`, runs `fetch-descriptions.ps1`, stamps the UTC `<!-- Last Updated: ... -->` comment, then FTPS-uploads all `*.htm` files. FTP credentials live in `MindAttic.Deploy/secrets/` (gitignored there).

## Codex

The Codex canon lives in `docs/`:

- `docs/BIBLE.md` — what the site IS, is NOT, its Laws. Project code: **MAC**.
- `docs/AMENDMENTS.md` — append-only change log.
- `docs/USER_STORIES.md` — capabilities and status.

Run `pwsh tools/codex.ps1 doctor` to validate. Run `pwsh tools/codex.ps1 digest` after editing `BIBLE.md`.
